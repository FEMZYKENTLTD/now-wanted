## Rules of use

- The student **confirms authorship/development** of `advanced_wa_bot` and of the projects in
  their GitHub repository (see `07-Evidence/advanced-wa-bot-attribution.md`).
- Do NOT claim the student wrote the pre-existing organizational code `wole.api.services`
  (authored by others) or that a sparse pre-SIWES repo (`whatsapptestbot`) represents SIWES
  activity.
- The dated commits under the student's name in `advanced_wa_bot` are supporting evidence of
  the student's authorship/development. Authorship is not downgraded simply because
  feature-by-feature evidence has not yet been separately catalogued.
- The reported 3,000+ → 0 debugging milestone is separate from authorship and is
  `STUDENT-REPORTED / EVIDENCE TO BE PROVIDED` (see `07-Evidence/student-debugging-contribution.md`).
- This file is separate from the student's pre-SIWES personal projects
  (see `01-Student-Information/student-profile.md` and `AGENTS.md` §9).
