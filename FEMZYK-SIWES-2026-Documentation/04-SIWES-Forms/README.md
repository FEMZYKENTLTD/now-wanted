# SIWES Forms Workspace

> Directory: `04-SIWES-Forms/`
> Status: Form documentation added. **No form fields, signatures or stamps are fabricated.**
> Physical completion is marked and left for the real student/supervisor.

## Purpose

Handle official SIWES forms carefully. For each form supplied (image/PDF): identify the
exact form → read every field → determine what can be completed from known information →
identify missing information → ask only for necessary missing info → produce copy-ready
answers → identify signature/stamp fields. **Never fabricate signatures or stamps.**

## Sub-folders

```

├── README.md

├── Other-Forms/              # logbook-signoff-requirements.md (signature/stamp areas)
└── SCAF/  Form-392/  Form-394/   # created only if/when the forms are required & supplied
```

## Form notes (provisional — verify before use)

- **SCAF** — signed & stamped by the organization; submitted with the acceptance letter to
  the nearest ITF office at the start of SIWES.
- **ITF Form 8** — at the end of SIWES, signed/stamped Form 8 + Log Book are submitted to
  the school. See `Form-8/form-8-completion.md`.
- **Forms 392 / 394** — **not automatically required.** Include only if current official
  requirements / the actual documents confirm they are needed. Verify (see
  `03-Official-Requirements/requirements-verification.md`).

## Signature & stamp rule

Wherever the industry supervisor signs, the organization's stamp must accompany the
signature. See `Other-Forms/logbook-signoff-requirements.md`. Completion markers:
`[TO BE COMPLETED/SIGNED/STAMPED IN PHYSICAL FORM]`, `[PHYSICAL SIGNATURE/STAMP REQUIRED]`.
